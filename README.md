# Laundry Care Website

## 1. Project Overview
Laundry Care is a web-based laundry management system developed to simplify laundry service booking and management. It allows customers to book laundry services online, view estimated service costs and check their booking status.

The system also provides an administrative section where administrators can manage customer bookings and monitor laundry operations.

## 2. Technologies Used
- HTML – Structure of the website.
- CSS – Styling and page layout.
- JavaScript – Client-side interactions and price calculations.
- PHP – Server-side processing.
- MySQL – Database management.
- WAMP Server – Local development environment.

## 3. Main Features

### Customer Features
- View available laundry services.
- Book laundry services online.
- Select service types and quantities.
- View estimated booking prices.
- Choose delivery options.
- Check booking status using a booking reference and phone number.

### Administrator Features
- Secure administrator login.
- View customer bookings.
- Manage booking information.
- Monitor booking statuses.

## 4. Available Laundry Services
- Washing – UGX 10,000 per load.
- Dry Cleaning – UGX 7,000 per garment.
- Ironing – UGX 5,000 per garment.
- Delivery – UGX 4,000.

## 5. Database
The website uses a MySQL database to store customer information, booking details, service information and booking statuses.

## 6. Installation and Setup

1. Install WAMP Server.
2. Copy the project folder into the WAMP `www` directory.
3. Start the Apache and MySQL services.
4. Open phpMyAdmin.
5. Create the required database and import the project SQL file.
6. Configure the database connection settings.
7. Open the website through your local browser.
